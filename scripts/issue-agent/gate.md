スクリプトの関門で次の問題が見つかりました。直してコミットしてください。
このフェーズは $CUTOFF に強制終了されます。`date` で時刻を確認し、残り 15 分を切ったら通っているところまでをコミットして終えてください。

```
$GATE_REPORT
```

## ルール

- `scripts/check.sh` を worktree で実行して、すべて通る状態にする。
- 未コミットの変更を残さない。ブランチを切り替えない、push しない。
- 問題の修正に必要な範囲だけを変更する。

## 出力

- `status`: 直し終えたら `done`。直せない事情があれば `blocked`(`summary` に理由)。
- `summary`: 何が原因で、どう直したか。
- `verified`: 実際に実行して通ったチェックのコマンド。
