レビュー(ラウンド $ROUND / $MAX_ROUNDS)で次の指摘がありました。
このフェーズは $CUTOFF に強制終了されます。`date` で時刻を確認し、残り 15 分を切ったら通っているところまでをコミットして終えてください。

```json
$FINDINGS
```

## ルール

- `severity` が `must` のものはすべて直す。指摘が誤りだと判断した場合は直さず、`summary` に反論と根拠を書く
  (次のレビューが判断する)。
- `should` と `nit` は、安全に直せるものだけ直す。
- 直したら `scripts/check.sh` を通し、すべてコミットする。ブランチを切り替えない、push しない。
- 指摘に無い変更を新たに加えない。

## 出力

- `status`: 直し終えたら `done`。直せない事情があれば `blocked`(`summary` に理由)。
- `summary`: 各指摘への対応(直した / 直さなかった理由)。
- `verified`: 実際に実行して通ったチェックのコマンド。
