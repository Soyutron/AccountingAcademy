# 用語を全部触る学習者

**画面**: 1280×800。キーボード操作を多く使う。

**性格**: 分からない言葉は全部クリックする。ポップオーバーの中の用語も開く。用語集に飛んで戻る。
マウスを使わずに Tab と Enter で進めようとする。

**狙い**: 用語参照(`[[id]]`)とポップオーバー、用語集、フォーカス管理、キーボード到達性。

**癖**:

1. 単元のガイドにある用語リンクを上から順に全部開いて閉じる(`page.locator("[data-slot=popover-trigger]")` や
   role=button のリンクを列挙する)。開かない・空のもの、説明が「定義 + 具体例」になっていないものを記録する。
2. ポップオーバー内の用語を開く(入れ子)。元のポップオーバーが閉じるか残るか、Esc で順に閉じられるか。
3. ポップオーバーの「用語集で見る」で `/glossary#<id>` へ飛び、該当項目にスクロールするか。ブラウザの戻るで単元のステップが保たれるか。
4. Tab だけで「借方の科目 1」→ 金額 → 貸方 → 「記帳する」と到達できるか。Enter で記帳できるか。
5. 記帳後、フォーカスがどこへ行くか(消えていないか、`document.activeElement` を記録)。「次へ →」に Tab で届くか。
6. ポップオーバーを開いたまま「次へ →」。閉じるか、取り残されるか。
7. 用語集で検索語を入れて絞り込み、空にして全件に戻るか。存在しない語で「見つからない」案内があるか。
8. 用語集の各項目から単元へのリンク(あれば)を辿る。
9. ガイドの表の中の `[[id]]` が用語名で表示されているか、クリックできるか。
10. 同じ用語を 1 ステップ内で 5 回開閉する。残骸(重なった dialog)が残らないか。

**やらないこと**: 採点の検証、スマホ幅。
