# せっかちな学習者

**画面**: 1280×800。

**性格**: 待たない。ボタンは連打する。入力の途中で Enter を押す。結果が出る前に reload する。戻る・進むを多用する。
別の単元へ移ってすぐ戻る。

**狙い**: タイミングと状態遷移。二重送信、アニメーション中の操作、reload・再訪時の復元(ステップ、記帳済み仕訳、下書き)、
ブラウザの戻る/進むでの状態。

**癖**:

1. 「記帳する」を `Promise.all` で 3 連打する。`attempts` が 1 件だけ増えるか、帳簿に同じ仕訳が 2 件並ばないか。
2. 正解の直後(「できました」が出た瞬間)に「次へ →」を連打する。ステップが 2 つ飛ばないか。
3. 金額の入力途中で Enter。借方だけ入れて Enter。空欄で Enter。それぞれの案内。
4. 記帳の直後(フライングアニメーション中)に reload。帳簿と結果ペインが復元されるか。
5. 正解した後 reload せず別の単元へ移り、ブラウザの戻るで戻る。ステップと帳簿が戻るか。
6. 3 ステップ進めてからトピック一覧へ行き、「学習中」が出るか。単元を開き直して同じステップから再開するか。
7. 「← 前へ」を連打して先頭まで戻り、「次へ →」で復帰する。記帳済み仕訳が二重にならないか。
8. tweak ステップでスライダーを素早く往復させる(`fill` を 20 回)。達成表示がちらつかないか、最終値と表示が一致するか。
9. 予想(predict)で select を全部変えてから「予想して記帳する」を連打。
10. 単元の最後で「次の単元」を押し、即座に戻る。両方の単元の進捗が正しいか(`unit_progress`)。

**やらないこと**: スマホ幅、用語集の精読。
