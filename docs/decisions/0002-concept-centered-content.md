# 0002. コンテンツは概念中心のテーマ軸を正本とし、資格別パスはそれを参照する

日付: 2026-11-07
状態: 採用

## 背景
初期の対象は日商簿記 3 級・2 級だが、将来は 1 級、公認会計士・税理士、企業研修、合格後の実務者まで広げる。
試験の級ごとにコースを作ると、同じ概念(例: 減価償却)が級ごとに分断され、級をまたぐ学習や合格後の参照に向かない。
また試験範囲の改定のたびにコンテンツ本体を組み替えることになる。

## 決定
- 知識の正本は **テーマ → 単元(深さ順)→ 概念** の構造で持つ。単元は試験の級ではなく深さ(1 入門〜4 専門)で並べる。
- 資格別の「合格パス」は単元の順序付き参照に過ぎない。試験固有の情報(範囲表、出題形式、配点、時間)はパスにだけ持つ。
- 概念は「前提」「関連」「対比」の関係でつながり、概念マップの可視化と前提チェックに使う。
- 勘定科目マスタ(科目 → 5 要素 → 理由)をコンテンツとして持ち、要素分類の演習と仕訳エディタの影響表示の両方がこれを参照する。

## 影響
- 試験範囲の改定はパスの編集だけで吸収できる。
- 同じ単元を複数のパスから参照できるので、2 級パスは 3 級パスの単元を前提として再利用する。
- 単元の執筆時に「どの級の内容か」ではなく「どの概念をどの深さで扱うか」を決める必要がある。執筆テンプレートで強制する(content-model.md)。
- ビルド時に参照整合性(存在しない概念・単元、前提の循環)を検査する仕組みが要る。
