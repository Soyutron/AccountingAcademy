# 0004. 図解はコードで描き、イラストは unDraw に絞り、AI 生成画像は学習コンテンツに使わない

日付: 2026-11-07
状態: 採用(詳細は `docs/visual-guidelines.md`)

## 背景
会計の概念を直感的に理解できる学習体験のため、図解・イラスト・アニメーションを積極的に使いたい。一方で、洗練された統一感、ライセンス(商用・将来の有料化)、拡張性を両立する必要がある。候補として「いらすとや」の活用が挙がった。

## 決定
- 会計の構造・流れ・期間の図解は、React + SVG の図解コンポーネントで描き、コンテンツからは YAML の `figure` ブロックで指定する。5 要素の配色と記号(ide-design.md 8 章)と自動で一致させる。
- 物語の場面のスポットイラストは unDraw に絞り、本サービスの基調色で再着色して使う。外部素材は台帳(`docs/assets-ledger.md`)で管理する。
- いらすとやは主要素材に使わない。理由: 無料枠が「1 制作物(または無料公開の 1 記事)につき 20 点」で、将来サブスクリプションを導入すると全体で 20 点の上限に戻る可能性が高いこと、誰もが知るスタイルがサービスの独自性と洗練を損なうこと。
- AI 生成画像は学習コンテンツに使わない(一貫性、正確さ、権利の扱い)。
- アニメーションは CSS を基本に、M1 で `motion` を導入する。Lottie / Rive は使わない。
- 独自のイラストスタイルはサービス名とブランドの決定後(M3 以降)に検討する。

## 影響
- M1 に図解ブロック(`elements` / `flow` / `timeline` / `taccount` / `proportion` / `compare`)の実装が入る。
- コンテンツ検査に `figure` ブロックのスキーマと `alt` 必須を追加する。
