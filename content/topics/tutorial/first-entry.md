## ようこそ
この画面が会計IDEです。ガイドで物語と「やること」を読み、仕訳帳に書き、結果の表で会社の姿が動くのを見ます。
まずは1件だけ記帳してみましょう。案内に沿って進めれば2分で終わります。

## 元手を入れてみる
あなたは練習用のお店を開きます。元手の100,000円をお店の現金にしましょう。
仕訳帳で、左(借方)に「現金100,000」、右(貸方)に「資本金100,000」と入れて、「記帳する」を押します。

```task
type: post
transaction: 元手として現金100,000円をお店に出資した
answer:
  debit: [{ account: cash, amount: 100000 }]
  credit: [{ account: capital_stock, amount: 100000 }]
wrong_patterns:
  - match: { swapped: true }
    misconception: debit_means_increase
    feedback: 現金は左(借方)で増えます。左右を入れ替えてみましょう。
  - match: { unbalanced: true }
    feedback: 左右の金額を同じにします。
hint: 左に「現金」、右に「資本金」。金額はどちらも100,000です。
success: 結果の貸借対照表に、現金と資本金が同時に現れました。これが記帳です。
```

## 結果の表を見る
結果の貸借対照表に現金100,000と資本金100,000が並んでいます。さっき記帳した直後は、動いたこの2つの行に「+100,000」と増えた額が出ていました。記帳のたびに、こうして会社の姿が変わります。
迷ったら「ヒントを見る」、答えを変えて2回間違えたら「答えを見る」が使えます。
